Before connecting real hardware

Never plug the ESP32's own USB port in while the scanner's battery harness is connected. Use the listen-only telemetry tap described in Live link: a 3.3 V USB-to-serial adapter with only RX ← TX0 (GPIO1) and GND connected, its VCC pin left unconnected.

This console only listens; it never sends anything to the scanner. Not physically tested yet.
