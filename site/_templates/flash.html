Flash the firmware from your browser

Installs Radar V5.1 firmware (release {{VERSION}}) on a classic ESP32-WROOM-32 DevKit over USB — no Arduino IDE needed. Works in Chrome or Edge on a desktop computer.

  1. Switch the scanner OFF and unplug the whole harness from the ESP32, including the J1 power plug.
  2. Connect the ESP32's own USB port to this computer with a data cable.
  3. Press Install, pick the board's serial port and confirm. (Hold the board's BOOT button if it does not connect.)
  4. Unplug the USB cable. Re-connect the harness, J1 last, checking every label. Switch ON.
  5. You should see the splash “EDU SONAR … NOT a safety device”, then the green sweep.

Never connect the ESP32's USB port while the battery harness is plugged in. This page is the ESP Web Tools installer (Apache-2.0, loaded from unpkg.com). The browser flasher has not yet been tested on a real board (test T-FLS-1). Prefer to build it yourself? arduino-cli compile --upload --profile esp32-core3 -p <port> firmware/Radar_V5
