Security and safety

This page covers two different things: keeping the repository's supply chain trustworthy, and keeping the physical instrument electrically safe.

Part 1 — Software supply chain

The relevant risk class is OWASP Top 10:2025 A03 — Software Supply Chain Failures: builds that silently pull in changed, compromised or unexpected components. What this repository does about it:

Verifying a release yourself

sha256sum -c SHA256SUMS                                   # file integrity
gh attestation verify ultrasonic-radar-scanner-v6.0.0.zip -R <owner>/ultrasonic-radar-scanner   # provenance (same for each app file)

Updating a pinned version

Change the version in sketch.yaml or requirements.txt only after a real build with the new version succeeds; commit the new compile record under docs/validation/, re-run python scripts/gen_sbom.py, and note it in CHANGELOG.md. Dependabot pull requests follow the same rule: CI must be green, and firmware bumps also need a bench re-test before release.

Reporting a vulnerability

Please use GitHub private vulnerability reporting (repository → Security → Report a vulnerability) rather than a public issue. Expect an acknowledgement within 7 days. In scope: the build scripts, workflows and anything that could make a published artifact differ from its source.

Part 2 — Electrical safety

The V6 design has no battery, so the battery hazards of earlier versions are gone. What remains:

  • Wire with USB unplugged, and check every wire against WIRING.md before powering up.
  • Use a 3.3 V-capable sensor (RCWL-1601 / HC-SR04P). A 5 V-only HC-SR04's echo can damage the ESP32 input unless it goes through the documented divider.
  • Measure P1 VIN before connecting the servo; never connect the servo to 3.3 V.
  • Power from a charger or power bank rated ≥ 1 A. Unplug it if anything gets hot or smells.
  • The servo is toy-grade and unguarded: keep fingers and hair away from the turning head.

Part 3 — What this instrument is not

It is an educational ultrasonic (sonar) instrument with a radar-style display. It is not a radio-frequency radar, not a safety device, and not an obstacle-avoidance or people-detection system. It does not scan 360°, its 200 cm display range is not a verified sensing range, and the angle shown is the commanded servo position rather than a measured one. The case carries this label engraved on its back and the firmware shows it on the start-up screen.
