Flash the firmware from your browser

Installs Radar V6 firmware (release 6.0.0) on an ESP32-2432S028R “Cheap Yellow Display” over USB — no Arduino IDE needed. Works in Chrome or Edge on a desktop computer.

  1. Connect the board's USB port to this computer with a data cable. The sensor and servo can stay connected.
  2. Press Install, pick the board's serial port and confirm. (Hold the board's BOOT button while it connects if it does not.)
  3. Wait for “Installation complete”. The board restarts by itself.
  4. You should see the splash “EDU SONAR … NOT a safety device”, then the green sweep.
  5. Colours wrong or screen mirrored? See the display settings in the assembly guide.

No firmware image in this build. The GitHub Pages deployment compiles the firmware and publishes it here; it is also attached to every release.

This page is the ESP Web Tools installer (Apache-2.0, loaded from unpkg.com). The browser flasher has not yet been tested on a real board (test T-FLS-1). Prefer to build it yourself? arduino-cli compile --upload --profile esp32-core3 -p <port> firmware/Radar_V6
